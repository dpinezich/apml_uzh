## Learning Objectives

By the end of this chapter, students will be able to:
- Explain what unsupervised learning is and why most real data is unlabeled
- Name the three questions you can ask unlabeled data (clustering, dimensionality reduction, anomaly detection) and what each returns
- Explain why evaluation without labels is hard and what "clusters ≠ classes" means
- Run `fit_predict` / `fit_transform` without a `y` (K-Means, PCA, IsolationForest one-liners)

## Content Outline

### Block 1 — What Is Unsupervised Learning? (7 min)
- Supervised: (X, y) → predict y. Unsupervised: X only → discover structure. The question changes from "What is this?" to "What is *in* this?"
- Why unlabeled data exists: labeling is expensive / impossible for future data / labels don't exist yet / we don't know what we're looking for. **Most data is unlabeled.**
- Mail-sorting analogy: several valid groupings.
- Visual: `find_groups.gif` — students count groups in grey blobs/moons/circles, then reveal.

### Block 2 — Three Questions (6 min)
| Question | Output column | Chapter |
|---|---|---|
| Which samples belong together? (clustering) | group id | Ch08 |
| Can I keep the information in fewer features? (dimensionality reduction) | new coordinates | Ch09 |
| Which samples are unusual? (anomaly detection / density estimation) | outlier flag | today, one line |

- One-liners: `KMeans(...).fit_predict(X)`, `PCA(2).fit_transform(X)`, `IsolationForest().fit_predict(X) == -1` — same sklearn grammar, **no y**.
- Mention only: Gaussian Mixture Models = "soft K-Means" (probabilities); generative models (VAE, diffusion) out of scope.

### Block 3 — The Evaluation Challenge (7 min)
- Visual: `two_valid_groupings.png` — k=2 left/right, k=2 top/bottom, k=4: all valid; usefulness depends on the question.
- Internal metrics (no labels): silhouette, inertia. External (if labels exist): ARI — a *sanity check*, not the objective. Domain sense / downstream usefulness.
- **Clusters ≠ classes** — say it here; Ch08 exercise relies on it.

### Block 4 — Applications (4 min)
Customer segments, disease subtypes, topic discovery, fraud/intrusion (anomaly), image compression / eigenfaces (PCA), 2-D visualisation of high-D data, recommender latent factors.

### Block 5 — Live Demo (12 min) → `02-examples/ch07_unsupervised_intro_examples.ipynb`
1. Iris with the label column deleted (petal features) — how many groups?
2. Blobs / moons / circles: count, then reveal
3. Anomaly detection in one line (IsolationForest on simulated transactions) — "unusual ≠ fraud"
4. 30-second digits teaser: 64 features squashed to 2, unlabeled view only (Ch09 does the rest)

### Block 6 — Quiz (3 min)
- Q1: "K-Means with k=3 gave 3 groups, so we have 3 customer types" — what's wrong? (K-Means always returns k groups.)
- Q2: 10 000 unlabeled X-rays + 200 labeled — which paradigm uses which? (Unsupervised uses all; combine.)

## Instructor Notes
- Spend the time on motivation and on the evaluation challenge — the "no right answer" feeling is the learning outcome.
- Do **not** teach K-Means or PCA here (Ch08/Ch09 do); the demo only shows what structure looks like.
- Whenever labels are used for colouring, say out loud that they were added afterwards.
- Anomaly detection appears only here — one line, one plot; DBSCAN's noise label in Ch08 is the second occurrence.
